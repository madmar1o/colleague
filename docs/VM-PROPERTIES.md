# Colleague — свойства виртуальной машины (VM)

Свойства задаются в `1cedt.ini` после `-vmargs` (или аргументами запуска EDT).
Все — необязательные: без них плагин работает в обычном режиме.

## Диагностика и самотесты

| свойство | эффект |
|---|---|
| `colleague.llm.smoke=true` | при старте список моделей с LLM-эндпоинта в stderr |
| `colleague.ui.selftest=true` | тестовый вопрос с приложенным контекстом, ответ в stderr |
| `colleague.search.selftest=true` | самотест поиска по индексу проекта в stderr |
| `colleague.browser.selftest=true` | сквозная проверка моста страниц (жест отправки прямо со страницы) |
| `colleague.browser.abortproof=true` | автономная проверка остановки хода внутри самотеста браузера |
| `colleague.agent.probe=<задержкаMs>` | живой зонд: через N мс после открытия вьюшки один агентский ход с read-only инструментами и фиксированным вопросом; трасса хода в консоли — проверка без человека |

## Отладочный веб-мост

| свойство | эффект |
|---|---|
| `colleague.webbridge.port=<порт>` | поднимает HTTP-мост страницы чата на localhost (токен в странице, API `/call`, `/events`); используется приёмкой `tools/acceptance/bridge_smoke.ps1` |
| `colleague.open.view=true` | автооткрытие вьюшки ассистента |

## Семантический слой (опционально)

| свойство | эффект |
|---|---|
| `colleague.semantic.store=<url>` | адрес векторного хранилища (Qdrant), включает семантический слой |
| `colleague.semantic.model=<имя>` | эмбеддинг-модель для семантического индекса |
| `colleague.semantic.embed=<url>` | эндпоинт эмбеддингов |

## Провайдер по умолчанию

| свойство | эффект |
|---|---|
| `colleague.provider=<имя>` | сессия работает на зарегистрированном провайдере с таким именем (переопределение поверх сохранённого default) |
