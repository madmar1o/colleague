## Сделано
1) Красный тест (коммит `566c56e`): `AgentProfileWriterTest` (8) — круг «что сохранили, то и
   читается» через `AgentProfileLoader`; однострочные поля не могут подделать вторую строку
   заголовка (`\n` в описании сворачивается); опасный id не попадает в файловую систему
   (`""`, `Bad Name`, `a/b`, `..\evil`, >64 символов); повторная запись правит файл на месте
   (один id = один файл); удаление снимает только свой файл; готовый текст сида кладётся байт в
   байт и читается загрузчиком; записанный файл с инструментами не перемешивается
   (`tools: read_file, search_code, write_file`). `AgentProfileLoaderTest` +2 — `title:` это
   отображаемое имя, имя файла остаётся id; без `title:` имя показа = имя файла.
   `PageCatalogEventsTest` +1 — карточка отдаёт форме `title/maxSteps/tools/system`, `label` =
   заголовок, `name` по-прежнему id.
   Реализация: `agents/AgentProfileWriter` (`save`/`saveText`/`delete`/`exists`, атомичная запись
   через временный файл и `ATOMIC_MOVE`), `AgentProfile` — `title`/`getDisplayName()`/
   `getToolNamesInOrder()`, `AgentProfileLoader` — поле `title:`, карточки
   `PageCatalogEvents.agents(...)`.
2) UI (коммит `d2fc98f`): `web/agents.html` — кнопка «+ агент», оверлей-форма (id, уровень
   хранения, имя для показа, описание, модель, лимит шагов, режим, инструменты, системный
   промпт), кнопка «изменить» на карточке, «Удалить» в режиме правки, id при правке закреплён;
   `AgentsPanel` — мостовые кейсы `saveAgent`/`removeAgent`, уровень карточки (`level`) считается
   по тому уровню слияния, чей файл выиграл, ответ формы — `saved {ok, error}`;
   `ColleagueView` — `agentsLevelDirectory` (личный `~/.colleague/agents` и проектный
   `.colleague/agents`, проектный уровень доступен только при открытом проекте),
   `colleagueDirectoryForWriting` (каталог ещё не создан), сид пишется **только в пустой**
   каталог, после записи каталог сбрасывается (`refreshAgentCatalog`).
3) Первый агент — файл, а не строка в коде: `bundles/com.mad.edt.colleague.ui/seed/agents/
   analyst-1c.md` (`title: Аналитик 1С`), добавлен в `build.properties` (`seed/`); текст читается
   из бандла и пишется тем же `AgentProfileWriter.saveText`, поэтому пользователь видит ровно
   тот файл, что лежит в репозитории, и может его читать/править/удалять. Удалённый сид не
   возвращается (запись только в пустой каталог).

## Критерии приёмки
На странице агентов: «+ агент» создаёт файл профиля на выбранном уровне, «изменить» открывает
форму с уже заполненными полями (имя, модель, шаги, режим, инструменты, промпт), «Удалить» снимает
файл; карточка показывает `title`, выбор по-прежнему идёт по id файла. Пустой каталог при
открытом проекте получает «Аналитик 1С» реальным файлом. `AgentProfileWriterTest` 8,
`AgentProfileLoaderTest` 5, `PageCatalogEventsTest` 8 зелёные; `node --check` JS страницы зелёный;
`mvnw -B clean verify` зелёный (EXIT=0, тесты 265+78+24).
