# AG-3 — Список агентов-контактов в чате и перенос провайдеров/моделей в шестерёнку

## Статус
**pending** (планирование). Делить на два коммита: AG-3a (список контактов), AG-3b (шестерёнка).

## Первоисточник
- Каталог профилей уже есть: `ChatPanel.setProfileSupplier` :342, `profileCatalog()` :924,
  `pickedProfile()` :937 (фильтрует `Mode.SUBAGENT`), `pickProfileName` :956; страница уже
  получает каталог в `catalog`-событии (:918) и умеет `pickProfile` (:652).
- `AgentProfile` (:16-20 `Mode` ALL/CHAT/SUBAGENT; имя, описание, модель, бюджет) — готовая
  «сущность контакта».
- Провайдеры и модели сейчас в настройках формы чата (строка выбора провайдера/модели) — их
  нужно убрать из шапки чата в диалог настроек (шестерёнка).

## AG-3a: список контактов (коммит 1)
1) Красный тест сборки каталога контактов (в `ChatPanelCatalogTest` или новом): в `catalog`
   событии у каждого контакта — `name`, `description`, `mode` (только профили с
   `Mode.ALL`/`Mode.CHAT` + встроенный «Колега по умолчанию» первым).
2) `chat.html`: левая колонка контактов (как чат-лист в мессенджере): аватар-буква, имя,
   описание; клик -> `apiCall("pickProfile", {name})`; активный контакт подсвечен; текущий
   контакт определяет шапку чата (имя+подпись уже приходят в `ready`/`status`).
3) Отдельная история на контакт НЕ делать (пока): переключение контакта = текущий диалог
   продолжается с новым профилем; разделение историй — отдельная будущая задача.

## AG-3b: шестерёнка (коммит 2)
1) Убрать из шапки чата элементы выбора провайдера/модели; в шапке — иконка шестерёнки.
2) Клик по шестерёнке -> `apiCall("openSettings", {})` -> открытие существующего диалога
   настроек провайдеров/моделей (работу диалога не менять); либо inline-панель страницы с
   теми же данными, если диалог недоступен из браузерного виджета — выбрать по факту
   проверки вызова.
3) Модель/провайдер остаются в статус-строке как отображение (только чтение).

## Критерии приёмки
В чате слева список контактов агентов (профили.workspace + «по умолчанию»), клик переключает
профиль (статус подтверждает выбор); в шапке нет выпадающих списков провайдеров/моделей,
настройки открываются шестерёнкой. Тест каталога зелёный, `node --check` зелёный,
`clean verify` зелёный.
