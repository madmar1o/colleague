# Colleague — ИИ-ассистент для 1С:EDT

Плагин-ассистент для среды 1C:EDT: чат с моделью прямо в EDT, понимание вашего
проекта (поиск и семантический индекс модулей), объяснение выделенного кода,
генерация методов и правки файлов проекта **с подтверждением каждой правки**.

Модель — на вашей стороне: локальный [Ollama](https://ollama.com) (данные не
покидают машину) или любой OpenAI-совместимый API (OpenAI, OpenRouter,
и любой свой шлюз) — ключ настраивается у вас в EDT.

## Требования

| | |
|---|---|
| 1C:EDT | **2026.1 (Ruby)** — других версий мы не тестировали |
| Java | EDT 2026.1 уже работает на Java 17, отдельно ставить не нужно |
| LLM | локальный Ollama **или** OpenAI-совместимый эндпоинт с ключом |
| Qdrant | опционально — только для семантического индекса (см. ниже) |

## Установка

1. Откройте в EDT: **Справка → Установить новое ПО…**
   (Help → Install New Software).
2. Нажмите **Добавить…**, в поле **Location** вставьте адрес сайта обновлений:

   ```
   https://madmar1o.github.io/colleague/
   ```

3. Отметьте группу **Colleague** → Далее → примите лицензию → готово.
4. EDT попросит перезапуск — согласитесь.

**Что за предупреждение про неподписанный контент?** Артефакты не подписаны
ключом доверия — это нормально для сторонних расширений. Подтвердите установку
(Finish Anyway), если вам доверен источник этого сайта.

**Запасной канал (офлайн):** скачайте `colleague-update-site-v*.zip` со страницы
[релизов](../../releases), проверьте контрольную сумму `SHA256SUMS` и ставьте
тем же диалогом через **Архив…** (Add → Archive).

## Первая настройка

1. Откройте вьюшку **Окно → Показать представление → Другое… → Colleague
   Assistant** (при первом запуске она обычно открывается сама).
2. Нажмите шестерёнку **Провайдеры**:
   - локальный Ollama по умолчанию уже на `http://127.0.0.1:11434` — достаточно
     запустить `ollama serve` и скачать модель (`ollama pull <модель>`);
   - для внешнего API добавьте провайдер: базовый URL + ключ (проверяется
     кнопкой «Проверить соединение»; сохранённый ключ наружу не показывается).
3. Напишите вопрос в поле ввода и отправьте (Enter). Ответ приходит частями по
   мере генерации.

## Как пользоваться

- **Вопрос своими словами** — ассистент сам прикрепляет найденный контекст
  проекта (поиск по индексу модулей).
- **Контекстное меню редактора/дерева проекта**: «Отправить в Colleague»,
  «Объяснить выделение», «Сгенерировать метод».
- **Режим правки** (переключается в чате): ассистент предлагает изменения
  файлов, каждый дифф показывается в окне сравнения, запись — только после
  вашего подтверждения. Два ESC — выход из режима правки.
- **ESC во время ответа** — остановить ход ассистента.
- Ассистент ведёт видимый план шагов сложных задач и может вести память уроков
  между сессиями (разрешается явно в настройках вьюшки).

## Семантический индекс (опционально)

Понимание проекта «по смыслу», а не только по ключевым словам. Требует
векторное хранилище [Qdrant](https://qdrant.com) и эндпоинт эмбеддингов.
Включается VM-свойствами в `1cedt.ini` (после `-vmargs`):

```
-Dcolleague.semantic.store=http://127.0.0.1:6333
-Dcolleague.semantic.model=<имя эмбеддинг-модели>
-Dcolleague.semantic.embed=<URL эндпоинта эмбеддингов>
```

Без этих свойств чат, поиск по проекту и правки работают как обычно.

## Обновление и удаление

- **Обновление:** Справка → Установить новое ПО → тот же URL → снимите галку
  «Скрыть уже установленное software», при появлении обновления — отметить и
  переустановить; либо скачайте новый релиз и повторите установку.
- **Удаление:** Справка → О продукте → Сведения о составе установки
  (Installation Details) → вкладка «Установленные компоненты» → Colleague →
  **Удалить…**.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Список моделей пуст | Ollama запущен? `ollama list` в той же машине |
| «Не могу подключиться» к внешнему API | базовый URL и ключ на странице Провайдеры; кнопка «Проверить соединение» |
| Ответы медленные | размер модели/количество токенов контекста у локальной модели |
| Вьюшки нет после установки | EDT перезапущен? версия EDT ровно 2026.1 (Ruby)? |
| Семантика не подключается | Qdrant доступен по указанному URL; свойства записаны после `-vmargs` |

Полный список диагностических VM-свойств — [docs/VM-PROPERTIES.md](docs/VM-PROPERTIES.md).

## Приватность

- Локальный Ollama: запросы и код проекта **не уходят с вашей машины**.
- Внешний API: запросы уходят на настроенный вами эндпоинт с вашим ключом.
- Плагин ничего не отправляет третьим сторонам, кроме выбранного вами LLM-эндпоинта.
